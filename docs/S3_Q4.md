# Stage 3 Q4 recipe

Q4 is the only Stage-3 training recipe exposed by this release.

## Candidate universe

- Source: 256,077 AudioMCQ strongAC + 33,875 AVQA original-recording candidates.
- Raw audio candidate asset: `s3_candidates` (A2_RAW_DIRECT.json); do not use
  cached-feature or chunk-pair S2 inputs for this stage.
- Audio-linked grouping connects shared recording metadata, audio identities,
  exact first-20-second hashes, and file paths.
- strongAC retains its historical 230,599 train / 25,478 probe split. AVQA uses
  resolved recording-path hashing, inheriting strongAC splits for shared paths:
  30,572 train / 3,303 probe. Joint train size is 261,171; probe size is 28,781.
  AVQA path grouping is not an exhaustive waveform/near-duplicate audit. The probe
  is not guaranteed to be unseen by S1/S2 and is not a public benchmark.

## Generative screening

For every candidate, teacher and S2 student each receive four prespecified
cyclic option orders. Both freely generate a full response. The official
content matcher judges whether each response names the correct option content.
No option logits, candidate ranking, or restricted decoding is permitted.

An item is called stable-correct only if the model is correct under all four
orders. The quadrants are:

| Quadrant | Teacher stable-correct | Student stable-correct |
| --- | --- | --- |
| A | yes | no |
| B | yes | yes |
| C | no | yes |
| D | no | no |

The teacher is the AudioMCQ-tuned Qwen2.5-Omni checkpoint
`inclusionAI/AudioMCQ-Mixed-To-Strong` at recorded revision
`1405063d68760b17c705b38a8fc6633a47bf68df`. The student is the fixed S2
LR200@906 checkpoint.

## Q4 sampling and presentation

For each seed, sample without replacement:

| A | B | C | D | Total |
| ---: | ---: | ---: | ---: | ---: |
| 19,200 | 13,440 | 3,840 | 1,920 | 38,400 |

The selected identity list is shuffled deterministically. A second deterministic
permutation moves the gold answer so exactly 9,600 examples occupy each answer
position. The target remains ordinary direct gold-answer text such as
`b) <gold option text>` with answer EOS retained. Quadrant labels never enter
the loss and examples receive no quadrant-dependent weight.

The manifest is stored rank-major because the frozen two-rank sampler consumes
contiguous halves. At step 200 the run has consumed 12,800 unique examples.

## Optimization

- fresh AdamW state from S2 model weights
- decoder LR 5e-6; mapper LR 2e-6
- warmup 18 updates
- cosine schedule horizon 600; minimum decoder LR 5e-7
- weight decay 0.01; gradient clipping 1.0
- two GPUs, per-rank batch 32, global batch 64, no accumulation
- Unchanged executed training runtime (configuration requests BF16; that label
  alone does not establish effective autocast precision). No S1 AMP repair is imported.
- checkpoints at 100, 200, 400, and 600

The reported model is fixed step 200 inherited from the prior protocol, not
newly selected on this extension's validation or test scores. The LR value is on the
600-update trajectory; do not shorten the schedule horizon to 200.
